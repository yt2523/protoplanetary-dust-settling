# C++ 移植验收报告（中文）

## 结论

**本轮验收：17 项数值校验 PASS + 1 项 EXPECTED_INSTABILITY + 1 项 branch-coverage = 0 失败。**

- 密度/气体/物理坐标逐点差实测为 **0**（在严格门 `|C-P| ≤ 1e-12 + 1e-10·|P|` 下成立，
  实测多数用例恰为 0，个别为 1e-16~1e-19 量级的浮点尾差），**不宣称“逐位一致”作为通用保证**。
- 质量平衡用**独立积分质量 + 出流累计通量**复核残差（不采信发出的 `mass_balance_error`），
  实测 ≤ 2.6e-16 量级；Python 独立累计的边界通量与 C++ 一致。
- Gauss 收敛（RMS 与 Linf，Python/C++ 各自对解析解）：严格递减，末对观测阶 0.9003（落在 [0.75,1.25]）。
- 一个 diff=.7 压力用例暴露继承的负密度（`min_rho=-0.01237`，Python 与 C++ 双侧一致），
  仅在「双侧负、全程有限、其余全部门通过」时判 EXPECTED_INSTABILITY，**任何异常/不匹配一律 FAIL**。
- branch-coverage 13 项断言全部通过（层流 L=4 钳制且 zmax/H>4、turb 网格=z·H、速度裁剪 cap_count>0、
  穿越 stop/continue 语义与 tf 一致、代表扩散 α≈1e-3 及可测质量流失）。

## 验收口径（严格按 PLAN/FINAL_REVIEW 预声明）

- 浮点比较统一 `EPS_ABS + EPS_REL·abs(P)`（1e-12 + 1e-10·|P|），无 1e-9 / 1e-6 的宽松门；`Nt`/步数精确相等。
- 缺失值策略：absent tf 双侧 NaN 视为匹配；任何 unexpected/unmatched NaN/inf 判 FAIL。
- 质量 `M = h·sum(rho)`；磁盘初值 dust=0.01·gas，advection 初值即 dust。
  **独立质量门**：从 CSV 剖面重算 `M_initial`、`M_final`，残差 `M_final-M_initial+Σ(dt·Flux_top)`，
  并独立比较 Python 累计边界通量与 C++ 发出通量（不信任 `mass_balance_error`）。
- 全程有限与逐步 min：Python 对**原始 upwind_method 加 wrapper**记录每次更新+初值的 min/finite 与实际调用数，
  并与 C++ 逐步记录逐条比较；代表性稳定用例 `min(rho) >= -1e-14·峰值`。
- CLI/库：`checked_step_count` 在 `int` 转换前校验有限 T≥0、有限 dt>0、有限 T/dt≤100000，
  在 run 循环之前阻断（拒绝 `1e308/1e-308` 巨量步，无运行后诊断兜底）；N 界 `[2,1000000]`；
  输出流开启异常并检查 open/flush，写失败返回非零。

## 关键数值结果

### t_actual 修正验证（同一穿越参数 stop 开/关）
- `turb_cross_stop`：`actual_steps < Nt`，`t_actual = actual_steps·dt`（非 Nt·dt）。
- `turb_cross_continue`：`actual_steps == Nt`（跑满），双侧 `t_formation` 相等（`same_tf_stop_cont=True`）。

### 层流钳制 `lam_clamp`（R=100, zmax=50AU, Nz=32, ~2000yr）
- `L=4.0`（钳制）、`zmax/H>4`、物理网格 `z_real ≠ z·H`（层流用 linspace 而非 z·H）；层流速度不裁剪。

### 代表扩散 `turb_diff_repr`（R=100, α=1e-3, Nz=64, zmax=2H, 请求 5000 yr，实际 4973.610706 yr, adv=.3 diff=.2）
- α≈1e-3（非 1e-20）；`cumulative_flux` 可测非零、且 > 1e-8·M_initial（`repr_cum_loss_gt_1e8=True`）；
  `M_final-M_initial = -cumulative_flux`（扩散向上质量流失，守恒），全程有限，`min_rho=8.8e-5 > 0`。

### 压力用例 `turb_diff_stress`（α=0.1, d_lim=0.7, Nz=48, 请求 1000 yr，实际 998.735546 yr）
- 合成算子不保证正性：`min_rho=-0.01237`，Python 与 C++ 双侧一致、全程有限；
  其余全部门通过，唯一失败项为 `min_rho_ok`，故判 EXPECTED_INSTABILITY（不裁剪、不计 FAIL / 不计 PASS）。
